# Colors

<span className="review-chip">Under review</span>

Acceso fácil is the only **dark** part of the app: a dark grey panel with white text and white options. It keeps the blue header of the main system and the **orange** of the chosen options (the same "attention" meaning as in the app).

<Canvas of={Stories.Palette} sourceState="none" />

## Contrast

| Pair | Ratio | WCAG AA |
|---|---|---|
| Text (`--af-text`) on the panel | 7.8 : 1 | ✓ (AAA) |
| Secondary text (`--af-text-muted`) on the panel | 5.9 : 1 | ✓ |
| Error (`--af-error`) on the panel | 4.7 : 1 | ✓ |
| Black text on an option and on a dimmed option (`--af-option-dim`) | 21 : 1 · 8.8 : 1 | ✓ |
| Dimmed option against the panel | 3.3 : 1 | ✓ (3:1 for controls) |
| Orange border of the chosen option, on the white option | 4.5 : 1 | ✓ |
| White "Respuesta" on orange | 4.5 : 1 | ✓ |
| Yellow focus ring on the panel | 5.5 : 1 | ✓ |
| Green confirmation bar · orange-light note bar | 6.1 : 1 · 3.8 : 1 | ✓ (decorative: the text says it) |

## Changes from the app

| App today | Design system |
|---|---|
| Error `#FFB38A` (4.49:1, just under AA) | `#FFB894` (4.7:1) |
| Note bar `--attention` on the dark panel (1.7:1, almost invisible) | `--attention-light` (3.8:1) |
| Secondary text `#E0E0E0` | `--gray-150` `#DEDEDE` (same look) |
| **Focus: a white ring** | **The yellow focus ring** of the whole app (5.5:1 on the panel) |
| Option hover `#E9E9E9`, dimmed hover `#C6C6C6` | `--fill`, `--line-strong` (same values) |
