# Chart

The three dashboard charts: **Ingresos vs Gastos** (line), **salario neto, this year vs last year** (bars) and **Distribución del gasto** (horizontal bars).
The first two are drawn in SVG by `chart.js`, using tokens for every colour and size; the horizontal bars are plain HTML and CSS.

<Canvas of={ChartStories.Dashboard} />

Move the pointer over a chart, or Tab into it and use **← →**: one tooltip shows every series for that month. **Ver datos en tabla** opens the same numbers as a table.

## Colours

| Token | Value | Series |
|---|---|---|
| `--chart-1` | `--primary` #0F62FE | Ingresos · this year |
| `--chart-2` | `--attention` #B64407 | Gastos |
| `--chart-compare` | `--gray-600` #666 (5.7:1) | Previous year |
| `--chart-grid` | 6% black | Gridlines |

- Blue + orange **pass the colour-blind check** (ΔE 33; validated with the dataviz palette script).
- **Previous year** uses `--chart-compare` = `--gray-600` #666, from the palette: neutral, so the blue of this year still leads.
- **No shade scales as categories:** the distribution uses one accent colour.
- Text never uses the series colour: labels, axis and legend are `--text-muted`; the coloured key next to the text carries the identity.

## Spec

| | Value |
|---|---|
| Plot height | `--chart-h` 192px |
| Line | `--chart-line-w` 2px · round joins · smooth curve |
| Area | series colour at `--chart-area-alpha` 10% |
| Bars | max 24px wide · **2px gap** between the bars of a month · 4px rounded top, square at the baseline |
| Gridlines | 5 hairlines (1px, solid) · ticks rounded and compact (0 · 2k · 4k) |
| Axis labels | Mono 10 · `--text-muted` |
| Hover (line) | vertical crosshair + 8px dots with a 2px white ring |
| Hover (bars) | the hovered month stays solid, the others fade |
| Tooltip | `tooltip--dark` · month in bold · one row per series with a line key · values bold |
| Legend | always for 2+ series, none for 1 · line key 16 × 3 (lines) · 12px square (bars) · Sans 12 `--text-muted` · hairline above |
| Table view | `<details>` "Ver datos en tabla" with a `table` |

## Horizontal bars · Distribución del gasto

The share of each IRPF category in the year's expenses (base imponible), from the biggest to the smallest. All ten categories are always listed, even at 0%. The card is `card--attention` (Gastos), with "Anual" as its subtitle.

<Canvas of={ChartStories.Distribution} />

| | Value |
|---|---|
| Markup | `<dl class="list list--sm list--bars list--attention">` · one `row row--bar` per category |
| Label | `row__label` · Sans 12 · `--row-bar-label-w` 136px · cut with … |
| Bar | `row__bar` · `--row-bar-h` 12px · `--radius-sm` · track `--canvas` · fill in the section colour (`--list-accent`) · decorative (`aria-hidden`) |
| Value | `row__value` · the % in words, right-aligned, `--row-bar-value-w` 40px |
| Rows | 4px padding · no dividers |
| Colour | **one** colour, the section's: no shade scales, no colour per category |

The percentage is written next to every bar, so the bar itself is only decoration: screen readers read "Seguridad Social, 52%".

## Accessibility

- The chart has a name ("Comparativa Ingresos · Gastos") and is reachable with **Tab**. The **← →** keys move month by month, and the tooltip is announced.
- Every value is also in **Ver datos en tabla**, so nothing depends on hovering or on seeing colour.
- With two series there's always a legend, so identity never depends on colour alone.
- Series and month names are inserted as text, never as HTML.

## CSS

The HTML in the **Code** tab only works together with this CSS. Copy both to get exactly the component shown here (in a prototype, CodePen, a test page…). It contains the fonts, **only the tokens Chart uses**, the base styles (focus ring), the icon class and the component's own styles, plus the styles of the other components that appear in its examples (Card, Banner, tooltip & toast, Tables, List row).

Charts are drawn by a script: add `components/chart/chart.js` (or `dist/mi-contabilidad-ds.js`) and call `lineChart(el, config)` / `barChart(el, config)`.

In the app you don't paste it: the whole design system is loaded once with `mi-contabilidad-ds.css`.
