# List row

The **lines** inside a card that aren't a full data table: one item, one line. Four kinds. Here they are shown **on their own**; each **Card view** link opens the same rows inside their card.

<Canvas of={ListStories.Playground} />
<Controls of={ListStories.Playground} />

## Kinds

| Kind | Use in the app | Parts |
|---|---|---|
| **Record** (`row`) | Últimas facturas (dashboard) | `__lead` number · `__title` name · `__meta` date · `__value` amount · `__trail` status dot |
| **Label → value** (`row row--kv`) | The box lines of the tax forms (c.01, c.03…) | `__label` (code chip + text) · `__value` |
| **Bar** (`row row--bar`) | Distribución del gasto (dashboard) | `__label` · `__bar-cell` (decorative `__bar` + `__value` %) |
| **Result** (`result`) | The end of the tax forms and the annual summaries | `__label` · `__value` · the colour comes from the result |

## Bar

<Canvas of={ListStories.Bars} sourceState="none" />

All the bars take **one colour**, the section colour (orange in Gastos). Each bar already has its name and its %, so the colour doesn't need to tell them apart; a scale of orange shades would suggest an order that isn't there, and the lightest shades would disappear on the grey track.

## Result

The line that says **what you have to pay**. Full width (no side margin when it sits in a tax form), tinted background, big amount. The colour comes from **the result, not from the section**.

<Canvas of={ListStories.Results} sourceState="none" />

<a href="./?path=/story/app-components-tables--tax-forms" target="_top">Card view →</a>

| State | Class | When | Background | Text |
|---|---|---|---|---|
| **A ingresar** | `result--pay` | Result > 0: you pay | `--attention-tint` | `--attention` (5.0:1) |
| **A compensar** | `result--credit` | Result < 0: carried to the next quarter | `--positive-tint` | label `--text-muted` · amount `--text` |
| **Sin actividad** | `result--none` | Result = 0 | `--canvas` | `--text-muted` |
| **Subtotal** | `result--sm` | An intermediate difference (IVA repercutido − IVA soportado) | `--surface` | `--text-muted`, smaller |

The label always says the state in words ("A ingresar…", "A compensar…"), so colour is never the only cue.

## Spec

| | Value |
|---|---|
| Row padding | regular `--row-pad-regular` 12px (forms) · `list--compact` `--row-pad-compact` 8px (dashboard) |
| Min height | `--row-min-h` 24px (fits a 24px status dot or icon button) |
| Divider | 1px `--line` between rows, none after the last |
| Text | default 14px (forms) · `list--sm` 12px (dashboard) · 14px on mobile |
| Gap between parts | `--space-16` (12px on mobile) |
| Number (`__lead`) | 500 · min-width 32px |
| Date (`__meta`) | `--text-muted` · **hidden on mobile** |
| Value | right-aligned · `--strong` 500 · `--accent` section colour + 500 · `--muted` `--text-muted` |
| Colour | `list--primary` (blue) · `list--attention` (orange) |
| Bar | height `--row-bar-h` 12px · track `--canvas` · fill section colour · 2px radius · label width 136px |
| Result | label Sans 16 · amount Sans 24 / 500 · padding 8px, sides `--card-pad-x` · min height `--result-min-h` 56px |
| Subtotal (`result--sm`) | label Sans 12 · amount Sans 16 |
| Annual footer (`result--footer`) | Mono 12 / 700 caps in the section colour · no background |

## Accessibility

- Record lists are `<ul>` / `<li>`, so screen readers say "list, 6 items".
- Label → value lists are `<dl>` with `<dt>` / `<dd>`, so each value is read together with its label.
- In bar rows the bar is decorative (`aria-hidden`); the percentage is what gets read.
- The status dot inside a row is a 24×24 `<button>` with an `aria-label` (see Selectors).
- The result has `role="status"`: when the amount changes, screen readers announce the new label and amount without moving the focus. Its orange text is `--attention` on the tint (5.0:1).
