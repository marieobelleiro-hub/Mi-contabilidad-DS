# Card

The **white block** that holds everything in the app, always on the grey page canvas (`--canvas`). One padding, one radius. It's used in two ways:

- **KPI card:** one figure with its label, for the dashboard and the top of each section.
- **Container card:** holds a list, a table, a chart or a tax form (Modelo 303 / 130).

## KPI card

**One component** for every figure card in the app: a **label**, an **amount** and an optional **subtitle**. Only the colours and the state change.

### Properties

| Property | Kind | Values | Default |
|---|---|---|---|
| Label | Text | always present | "Total facturado" |
| Label colour | Variant | Black · Blue · Orange | Black |
| Amount | Text | calculated by the app | "50.790,36 €" |
| Amount colour | Variant | Black · Blue · Orange | Black |
| Subtitle | Boolean + text | optional, always black | on |
| Info button (ⓘ) | Boolean | next to the label · not on interactive cards | off |
| Interactive | Boolean | the whole card is a link to its page | off |
| State | Variant | Default · Hover · Focus · Selected · Disabled | Default |

### Colour rules

The app picks the colours automatically with these rules:

| Where | Label | Amount | Example |
|---|---|---|---|
| Dashboard · income | **Blue** | Black | Salario neto del mes, Previsión de ahorro |
| Dashboard · payments | **Orange** | Black | IVA a pagar, IRPF a pagar |
| Facturación | Black | **Blue** | Total facturado, Cobrado, IRPF retenido |
| Gastos | Black | **Orange** | Total gastos, IVA soportado, Total gastado |
| Pending, in any section | Black | **Orange** | Pendiente de cobro (still to be solved) |
| IRPF periods | Black | **Blue** | IRPF acumulado (3T) |

The subtitle is always black. Never colour both the label and the amount.

### Spec

| | Value |
|---|---|
| Background · radius | `--surface` on `--canvas` · `--card-radius` 8px |
| Padding | `--card-pad-y` 20px · `--card-pad-x` 24px (20px on mobile) |
| Label | Title · Sans 16 / 400 · `--text`, `card__label--primary` (blue) or `--attention` (orange) |
| Amount | Display · Emphasis · Sans 24 / 500 · `--text`, `card__amount--primary` or `--attention` |
| Subtitle | Mono 12 · `--text` |
| Label → amount → subtitle | `--space-8` |

| Selected outline colour | `card--primary` (blue) / `card--attention` (orange): follows the amount |

## Container card

For lists, tables, charts and tax forms: a **header** (title + actions), a **body** and an optional **footer**. Containers are **fully responsive**: one component for desktop and mobile; on mobile the padding goes down to 20px and wide content (tables) scrolls sideways.

### Tax form

The **Modelo 303** (IVA) and **Modelo 130** (IRPF) quarter forms. Same structure for both; only the colour changes: **orange** for IVA, **blue** for IRPF. The deadline is always orange.

**Anatomy:** the card has no outer padding (`card--sectioned`). The header and each block pad themselves and are separated by hairlines. Everything inside comes from other components:

| Part | Example | Built with |
|---|---|---|
| Header | MODELO 303 · 3T · JUL–SEP 2026 | `card__header` + `card__title card__title--caps` |
| Deadline | Plazo: 20 de octubre | `card__due` (Sans 14, always orange) |
| Block | Ingresos con IVA · España | `card__section` + `card__section-title` (Mono 12 caps, section colour) |
| Box row | `c.01` Base imponible · 9.622,45 € | **Row** `row--kv` (see Parts · rows) + **Chip** `chip--code` |
| Highlighted amount | IVA repercutido 2.020,71 € | `row__value--accent` (section colour, 500) |
| Secondary amount | Retenciones acumuladas 1.443,37 € | `row__value--muted` |
| Subtotal | IVA repercutido − IVA soportado | **Result** `result--sm` (see Parts · rows) |
| Compensation | ☑ Aplicar compensación · 151,80 | **Checkbox** `check` + **Input** `input--sm input--num` |
| Result | A ingresar este trimestre · 1.778,23 € | **Result** `result--pay`, full width (see Parts · rows) |
| Payment | Importe ingresado en Hacienda | `row--kv` + **Input** `input--sm input--num` |
| Notes | Notas del trimestre | **Input** `textarea.input` |

The colour is set once on the card: `card--attention field--attention` (IVA) or `card--primary field--primary` (IRPF), plus `list--attention` / `list--primary` on the rows. Section titles, highlighted amounts and the focus colour of the fields follow it.

| Part | Class | Content |
|---|---|---|
| Header | `card__header` | Title on the left · actions (ⓘ, ghost button) on the right · 16px under it |
| Title | `card__title` (`--caps`, `--accent`) | Title · Sans 16 / 400 |
| Body | `card__body` (`--scroll` for wide tables) | List, table, chart… |
| Footer | `card__footer` | Totals on the left · action on the right |
| Section | `card__section` + `card__section-title` | Form block with an H3 (Label style: Mono 12 caps, accent colour) |

## Accessibility

- A card that opens something is a real `<a>` or `<button>` (`card--interactive`), not a `<div>` with `onclick`.
- Panels are `<section>` with `aria-labelledby` pointing to their title, so screen readers can jump between them.
- Titles use heading elements: `<h2>` for card titles and KPI labels, `<h3>` for sections.
- The selected period uses `aria-current="true"` as well as the outline, so the state isn't shown by colour alone. The other periods carry `aria-disabled="true"`.
- An interactive card is one link: don't put a button (ⓘ) inside it.
