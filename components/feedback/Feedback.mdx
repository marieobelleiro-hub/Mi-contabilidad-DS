# Banner, tooltip & toast

Messages that **inform** the user without being part of the data.

| | Use | Where it lives |
|---|---|---|
| **Banner** | Something to know about this section: a tip, a warning, an error | Inline, inside the page or a card |
| **Tooltip** | An explanation behind an ⓘ button · the values under the pointer on a chart | Pops up next to its trigger |
| **Toast** | Confirmation after an action ("Factura 411 eliminada."), with an optional action | Bottom left of the screen, disappears after a few seconds |

## Toast

A short confirmation at the bottom of the screen. Write the **Text**, choose the **Action** and the **View**: each one shows the whole screen (desktop scaled down, with the sidebar strip; mobile at 390px), so you see where the toast sits.

<Canvas of={FeedbackStories.Toast} sourceState="none" />
<Controls of={FeedbackStories.Toast} />

| Action | Use |
|---|---|
| **Deshacer** | After deleting: "Factura 411 eliminada." · "Gasto de Jazztel eliminado." (the two toasts of the app) |
| **Entendido** | Future: a message you only need to acknowledge |
| None | A plain confirmation |

| | Value |
|---|---|
| Background / text | `--black` / `--white` · Sans 14 |
| Padding | 12 / 16 |
| Position | `toast--start`, 24px from the bottom |
| Width · desktop | **fixed** `--toast-w` 400px, starting after the sidebar (`--sidebar-w` + 24px), so it never covers the assistant buttons · longer messages wrap onto several lines |
| Width · mobile | the **full width** of the screen, 16px margins left and right |
| Action | `toast__action`: Mono 12 caps · `--primary-light` (8.9:1 on black) · 24px tall |
| Timing | stays 6s with an action, 3s without · fades in 0.2s (no animation if the user prefers reduced motion) |
| Focus | when the deleted row had the focus, it moves to the action, so keyboard users can undo |

## Accessibility

- **Banners:** info is `role="status"` (read when convenient); warnings and errors are `role="alert"` (read straight away).
- **Tooltips** open on click and keyboard, not only on hover, so they work on phones and without a mouse. The ⓘ button says what it explains ("Más información: Salario neto del mes") and reports `aria-expanded`. Esc closes the tooltip and returns focus to the button.
- **Toasts** are announced with `aria-live="polite"` without moving focus. The Deshacer button is reachable with the keyboard while the toast is visible.
- Colour is never the only cue: warnings and errors always say what's wrong in words.
