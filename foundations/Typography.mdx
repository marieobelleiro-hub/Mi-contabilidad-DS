# Typography

Two families: **IBM Plex Sans** for content and **IBM Plex Mono** for labels and navigation. Five sizes: **24 · 16 · 14 · 12 · 10**.

## Typeface: IBM Plex

The app uses **IBM Plex**, an open-source type family (SIL Open Font License) designed by IBM. Its sans and mono share the same proportions, so they sit well together on one line: Sans for what you read, Mono for what you scan (labels, navigation, codes). IBM Plex can be downloaded from the [Plex GitHub repository](https://github.com/IBM/plex) or loaded from Google Fonts.

|---|---|---|
| IBM Plex Sans | `--font-sans` | 300 · 400 · 500 |
| IBM Plex Mono | `--font-mono` | 400 · 700 |

If the font can't load, the app falls back to the system sans (`-apple-system`) and Courier New.

## Modifiers

Weight, colour and case are **added on top** of any style. They never make a new style: grey text in a table is still **Small**, a blue title is still **Title**.

| Modifier | Values | Example |
|---|---|---|
| **Weight** | See **Weights** above | <span style={{ fontFamily: sans, fontSize: 14, fontWeight: 500 }}>4.500,00 €</span> · <span style={{ fontFamily: mono, fontSize: 12, fontWeight: 700, ...caps }}>1T · Ene–Mar</span> |
| **Colour** | Any text colour token: `--text` · `--text-muted` · `--primary` · `--attention` · `--error-dark` | <span style={{ fontFamily: sans, fontSize: 12, color: 'var(--text-muted)' }}>30/09/2026</span> · <span style={{ fontFamily: sans, fontSize: 16, color: 'var(--primary)' }}>Salario neto</span> |
| **Uppercase** | `text-transform:uppercase` + `--ls-caps` letter spacing, always together | <span style={{ fontFamily: mono, fontSize: 12, ...caps }}>Ver todas</span> |

## Line height & letter spacing

| Token | Value | Use |
|---|---|---|
| `--leading-tight` | 1.2 | Big numbers, titles |
| `--leading-normal` | 1.45 | Body text |
| `--leading-relaxed` | 1.6 | Tooltips, dialog text |
| `--ls-caps` | 0.088em | Uppercase text only |

## Headings

| Level | Element | Style |
|---|---|---|
| H1 | `<h1 class="sr-only">` | Hidden — one per section, for screen readers |
| H2 | `<h2>` | **Title** |
| H3 | `<h3>` | **Label**, uppercase, in the section colour |

## Rules

- Only the five sizes and the weights above.
- Uppercase only with `text-transform`, never typed in capitals.
- **Don't rely on colour alone.** If a colour or bold text means something (paid, error, total), say it in words too, so it's clear to people who can't see the difference.
