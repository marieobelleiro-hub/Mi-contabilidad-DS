# Spacing, radius & elevation

## Spacing

Every `padding`, `margin` and `gap` uses one of these **10 tokens**: even values on a 4px scale with a 2px half-step.

<table style={{ width: '100%', borderCollapse: 'collapse' }}>
  <tbody>
    {SPACES.map(([v, use]) => (
      <tr key={v}>
        <td style={{ ...cell, ...code, whiteSpace: 'nowrap' }}>--space-{v}</td>
        <td style={{ ...cell, ...code, color: 'var(--text-muted)' }}>{v}px</td>
        <td style={{ ...cell, width: '40%' }}><div style={{ width: v * 4, height: 16, background: 'var(--primary)' }} /></td>
        <td style={{ ...cell, ...muted }}>{use}</td>
      </tr>
    ))}
  </tbody>
</table>

- Negative margins: `calc(-1 * var(--space-8))`.
- Row densities: **compact** `--space-8` (tables) · **regular** `--space-12` (lists).
- No other values.

Cards sit flat on the canvas. Shadows only mark something that floats (a tooltip) or reacts to the pointer (a clickable card).

## Layers

What sits on top of what, from bottom to top:

| Token | Value | Use |
|---|---|---|
| `--layer-raised` | 1 | A focused tab above its neighbours, so the focus ring isn't hidden |
| `--layer-tooltip` | 50 | Tooltips |
| `--layer-toast` | 990 | Toasts |
| `--layer-dialog` | 1000 | Overlays that aren't a native `<dialog>` (native dialogs always sit on top by themselves) |

## Motion

| Token | Value | Use |
|---|---|---|
| `--motion-fast` | 0.1s | Hover, focus, small state changes |
| `--motion-slow` | 0.2s | Toast appearing, switch, bars growing |

When the user's system asks for **reduced motion**, transitions are switched off.

## Focus ring

One style everywhere: `outline: var(--border-thick) solid var(--focus)` with `outline-offset: var(--focus-offset)` (2px), plus a 1px black halo so it's visible on any background.

<button type="button" className="btn btn--primary" style={{ outline: '2px solid var(--focus)', outlineOffset: 2, boxShadow: '0 0 0 1px var(--black)', margin: '8px 0' }}>Focused button</button>

## Breakpoint

**Desktop from 1024px.** Below that, the mobile layout applies (cards with 20px padding, 12px gaps, 16px text in form fields). CSS can't use tokens inside media queries, so this value is written as `@media (max-width:1023px)` in each component.
