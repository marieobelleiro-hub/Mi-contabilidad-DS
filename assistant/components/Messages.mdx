## Accessibility

- The conversation is a `role="log"` with `aria-live="polite"`: each new reply is read out once, without moving the focus.
- Each message starts with a hidden "Tú:" / "Asistente:" so screen readers say who is speaking; the colour and the side are not the only cue.
- "Pensando…" is `aria-hidden`: only the real answer is announced.
